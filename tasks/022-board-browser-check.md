# 任务 022：原型 v7 第 1 批浏览器检查（只检查，不改代码）

报告 `tasks/022-report.md` 的第一行写 `session-id: <你的会话 ID>`。

## 背景

任务 021 把原型的数据模型从 v4 的"项目 → 流程 → 节点"换成了 v7 的"项目 → 看板 → 卡片"，并做了依赖图、状态列两种看板视图、筛选和看板上的直接操作（见 `tasks/021-board-data-model.md`、`tasks/021-report.md`）。021 的测试在 Node 的 DOM 桩里运行，**真实排版、拖拽、窄屏和深色模式从未在浏览器里看过**，这是本次检查的重点。

**先读：** `tasks/021-report.md`（尤其"给任务 022 的提示"）、`FEATURES.md` 1.2、1.3、10.3、第 11 节项目 B。

## 要做的内容

1. 启动静态服务：`python3 -m http.server <空闲端口> -d prototype`，不要用 8787。无头浏览器用 Playwright（装在项目目录以外）或本机 Chrome headless；视口 1440×900，浅色。
2. 场景（截图保存到 `evidence/022/`，文件名以场景编号开头）：

| 编号 | 场景 | 要断言的 |
|---|---|---|
| S01 | 打开项目 B，默认显示依赖图 | 卡片按状态着色；设计、开发、运行时设计、调研、缺陷五个分组都有色块；缺陷分组的卡带"示例"标记 |
| S02 | 卡片外观 | 抽查 3 张卡：标题、状态、负责人、分组标签、测试进度、"规格 vX · 产出 vY"都显示，且与数据一致；文字没有被截断到看不懂 |

| S05 | 状态列视图 | 切换到状态列；每张卡只在一列；已暂停、已取消默认折叠，可以展开 |

| S12 | 取消卡 | 取消一张有下游的卡；它进入已取消，下游显示"上游已取消" |
| S13 | 键盘路径 | Tab 聚焦卡片 → 打开卡片菜单 → "添加依赖到…"完成连接；Esc 关闭菜单 |
| S14 | 项目 A | 8 张卡、分组"承接评估"、没有条件分支的界面元素 |
| S15 | 卡片详情 | 从看板点开一张卡；能看到规格（每条带来源）、依赖（上下游、父子卡、产出版本历史）、执行过程 |
| S16 | 其他页面冒烟 | 收件箱、代理库、经验库、决策记录、项目记忆、项目设置逐个打开并截图；没有空白页、没有报错；页面上没有席位安排、自主度设置表、流程变更请求、项目 C |
