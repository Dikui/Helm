## 数据模型与文件拆分

`db.projects` 保存项目，`db.cards` 按 ID 保存卡片，项目通过 `cardIds` 引用卡片。**依赖只存于卡片的 `dependencies`**，图需要的边由 `projectEdges()` 临时派生，避免两个持久数据源失去一致性。父卡是 `parentId`，子卡通过反向查询得到，不默认把父子关系当作执行依赖。

卡片保存：标题、需求、边界、四类测试与四态结果、交付物、带出处说明的资料来源、依赖、多分组标签、父卡、负责成员、预算/花费、规格版本及历史、产出版本及历史、使用过的上游版本、上游已变标记、状态行与尝试。规格的需求/边界/测试逐条带六类来源之一。成员引用代理；会话未知时为 `null` 或“未记录”，不造 ID。

`specHistory`、`outputHistory` 递归冻结，重新验收追加新快照，旧对象不可修改。`reopenCard()` 只把已验收改为进行中，清除旧独立验证，不增加产出版本；下一次验收才 +1。标签和依赖属于看板组织信息，本批修改它们不增加需求/边界/测试的规格版本。规格编辑不在本批提供。

为了后续批次能分别维护数据、布局和页面，拆为四个本地脚本，严格按 HTML 顺序加载：

1. `prototype/data.js`：项目 A/B、卡片、成员引用、代理、经验、决策的初始数据。
2. `prototype/board.js`：011/017 的分层、重心排序、文字换行、折线避障和端口算法，以及分组包围几何。
3. `prototype/artifacts.js`：沿用静态产出物预览数据、Markdown/CSV/diff 渲染与抽屉交互。
4. `prototype/app.js`：看板筛选、视图、操作、详情和其他页面。

`prototype/index.html` 保留外框与 CSS；只用普通 `<script src>`，没有模块导入、外部库、CDN、构建步骤。直接打开 HTML 或用静态服务均可。所有交互只在当前页面内存中保存，刷新恢复 Demo。

## 看板与直接操作

依赖图默认显示，沿用分层和两次重心排序；标题和元信息按宽度换行，状态文字及边框着色。每个分组用有实色边界的浅/深区域包住本组卡片；为了不把别组卡片也圈入，跨层或不相邻的同组采用多个同色色块。**只有第一个标签决定色块，全部标签都显示并可筛选**。父卡“折叠/展开子卡”隐藏全部后代并重新布局，状态列也使用同一折叠结果。

状态列按八状态分列，每张卡只在一列；已暂停、已取消用原生 `<details>` 默认折叠，可手动展开。窄屏改为纵向单列，桌面在主区内横向滚动。图过宽时只在图容器内滚动；≤760px 使用竖排与菜单替代拖拽。卡片详情的依赖页有直接上下游小图。

两种视图共用一个筛选状态：分组、状态、负责人（按代理汇总当前成员责任配置）、只看我要处理的。多条件取交集，后者本批只匹配待验收。切换视图、改变窗口宽度和父卡折叠不清空筛选；过滤/折叠只改变投影，不修改真实依赖。

默认点击卡片打开详情。“编辑看板”后点击/Enter 打开卡片菜单；普通浏览状态可按菜单键或 Shift+F10 打开菜单。菜单提供添加依赖到、管理连线、标签、取消；方向键、Home/End、Enter、Esc 可用，Esc 后回到原卡。桌面连接点走指针捕获、实际 SVG 坐标命中目标、可连接/禁止样式与原因提示，与键盘共用同一个连接函数。拖拽取消、切页、筛选或重排会清理临时状态。

- 新建：填写标题及多个标签，表单展示草稿预览；确认后立即入库，写“你”的决策。
- 添加 / 删除依赖：当场修改卡片依赖与使用版本，立即重排并记决策。
- 即时拒绝：自身、重复、循环、跨项目（以及不存在的卡片）；给出中文原因，不改变数据或决策记录。
- 影响确认：涉及进行中、待验收、已验收、已合并卡片或这些下游时，先显示本次改动与受影响卡片/状态；取消完全不生效，确认直接生效。标签输入在取消后保留。
- 标签：逗号分隔，去重，首标签改变色块；属于直接看板操作，不创建审批事项。
- 取消：保留卡和历史/依赖，只改为已取消；所有依赖它的卡明确显示“⚠ 上游已取消”，交项目负责人后续处理。已结束的合并/登记卡与已取消卡拒绝再次取消。

保留表单预览和影响确认预览；工具条下显示最近已立即生效的改动及决策者。v4 的“暂存整批草稿 → 提交批准 / 放弃”不再存在。直接操作没有撤销旧草稿的按钮；加错依赖可通过连线菜单删除，这同样留下新决策。
