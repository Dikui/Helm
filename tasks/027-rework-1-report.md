## 1. 验收或打回后焦点丢失

原因：详情重绘后，旧焦点按 onclick 描述恢复到已禁用的验收按钮；浏览器不能聚焦该按钮，实际退到 BODY，详情的 Esc handler 就收不到事件。

修法：验收摘要提供固定的 `#acceptance-outcome`，文件页提供 `#annotation-outcome`，均有 `role=status`、`tabindex=-1` 和明确的焦点环。申请、验收通过、合并失败退回、登记、批注一次发回等处理完成后，显式聚焦当前标签页的结果提示，浏览器可将结果滚入可见区域。通用焦点恢复同时跳过禁用控件。待验收摘要中的“打回”进入文件页并聚焦文件标签；实际打回仍通过一次性发回批注完成。

R01 覆盖产品项目合并通过/失败、A 登记、批注打回，断言焦点落到新 DOM 中的结果提示，Esc 关闭详情并回到原看板卡片。保留原打开来源；若验收使原收件箱条目消失，沿用原有返回收件箱标题的后备路径。

## 2. 状态说明不更新

原因：操作区使用固定的“本卡仍在进行中”文本，没有读取卡片当前状态。

修法：摘要与操作区共用状态说明函数。进行中说明验证不会自动申请；待验收说明等待你的决定；已验收说明等待 runtime 合并/登记；已合并与已登记按项目类型区分并显示产出版本；退回进行中显示批注或合并重跑的原因。草稿、待开工、暂停、取消也有对应说明。成功合并/登记后清除旧退回原因。

R02 覆盖八状态、产品合并与非产品登记、合并重跑失败退回、自动验收；摘要和操作区文字均与数据状态一致。

## 3. 状态行编辑区占用顶部

原因：信息带显示状态行后，顶部又常驻一个重复状态行、大文本框、保存按钮和历史区块。

修法：信息带只有一份状态行文字和“编辑”按钮。点击编辑才生成文本框、保存/收起按钮与历史；收起后删除编辑区，焦点回编辑按钮。切换卡片或重新打开详情时默认收起。状态行历史也放进记录标签，收起编辑后仍可查阅。

桌面概览区（详情标题、信息带、附注、卡片操作与告警）最大为 `60dvh`，过长内容在概览区滚动；标签紧接概览区。1440×900 下，默认收起编辑时，补测使用的高度上界为 `16 + 900×60% + 32 + 44 = 632px < 900px`。移动端解除概览区高度限制，继续整体滚动。

R03 遍历全部 21 张卡，检查默认无编辑框、状态行只出现一次、概览与标签的 DOM 顺序，以及上述真实 CSS 高度约束；同时验证编辑、保存决策与历史、收起回焦点和记录页历史。**632px 是 CSS 布局条件的上界，不是浏览器实测标签坐标**；复检仍需截图与 boundingBox 确认。

原因：验收页从模拟身份、代理、方法等操作控件开始，读报告前需要跨过整个演示表单。
