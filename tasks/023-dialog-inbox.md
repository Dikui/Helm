## 要做的内容

### 1. 整体布局（10.1）
- **顶栏**：项目名、预算与花费、活跃成员数、收件箱计数、暂停按钮。暂停按钮本批只放位置，点击后提示"第 3 批提供"。
- **右侧是项目对话**，可以收起和展开；点开卡片时，卡片详情从右侧滑出，覆盖项目对话，关闭后回到对话。窄屏（≤ 760px）下对话和卡片详情改为全屏面板，有明显的返回按钮。

### 2. 项目对话（10.4）
- 你和项目负责人的唯一对话，按时间显示消息；你可以输入新消息（原型里由脚本给出预设的回复，不接真实模型）。
- **访谈**：每轮按 Q1…Qn 展示，每题附推荐答案，标明是关于需求、边界还是验收标准；可以逐题回答，也可以"采纳推荐答案"；整轮答完后出现下一轮或结束说明。
- **提议以卡片形式出现**：一组卡显示每张卡的规格摘要和整组的**组织理由**，有"确认 / 修改 / 驳回"。确认后卡片出现在看板上（状态为待开工）；修改打开一个表单改标题、需求、分组后再确认；驳回写明理由。三种结果都写进决策记录。
- **代你做的决定**：项目负责人按授权说明自己做了的决定，在对话里显示为一行说明，可以点开决策记录中的对应条目，也可以直接撤销。
- **成员的提问**：由项目负责人转给你，标明"来自卡 X 的成员"。

### 3. 收件箱（10.2）
只列需要你处理的事，分四组：
- **待回答**：访谈、项目负责人的提问（含转来的成员提问）、等你回答的决策关卡；
- **待批准**：项目负责人按授权说明提交给你的事项（例如新范围的卡）；
- **待验收**：待验收的卡；
- **硬约束事项**：对外动作申请、预算到达上限、副作用状态不明。

每一项链接到对应的卡、对话中的位置或决策记录；处理后从收件箱消失。被项目负责人代为处理的事不进收件箱。去掉 v4 留下的旧分组。看板筛选"只看我要处理的"改为匹配收件箱里所有与卡片相关的事项。

### 4. 你的要求（8.2）
- **项目记忆页**加入**项目指令、项目要求、授权说明**三项，都是可编辑的自然语言文本，显示最后修改时间和修改人；修改写进决策记录。
- 新建项目时，按项目类型填入默认的项目要求（`FEATURES.md` 1.1 的表）。
- 项目设置页去掉 v7 已取消的内容；自动验收条件、预设指派规则只显示当前值，编辑在第 4 批或以后做。

### 5. 决策记录与撤销（B10）
- 决策记录页：列出全部决策，标明决策者（你 / 项目负责人 / runtime 自动）、理由、是否原样采纳；显示组织理由与代你做的决定；有采纳率统计。
- **撤销项目负责人代做的决定**：撤销后写一条新的决策记录；受影响的卡按"重开"处理（已验收的回到进行中；未开工的回到草稿），在看板上能看到变化。原记录保留，标"已撤销"。你自己做的决定和 runtime 的自动记录不提供撤销。

### 6. Demo 数据
- **项目 A**（示例，`FEATURES.md` 第 11 节）：
  - 项目对话里有**两轮访谈**问答，每题附推荐答案，其中一题关于验收标准；
  - 项目负责人提出"技术可行性 ∥ 交付产能 ∥ 成本报价 ∥ 市场调研 → 汇总结论"一组卡，组织理由"四个维度互不依赖，并行最快"，已被你确认（保留在对话历史里）；
  - 授权说明写有"新范围的卡先问我"；项目负责人提议"交付"分组的一组卡，**作为新范围进入收件箱的待批准**，确认后出现在看板上；
  - 硬约束事项：「市场调研」达到预算上限（与第 1 批的已暂停状态对应）。
- **项目 B**（真实记录 + 示例）：
  - 至少一条项目负责人代你做的决定（例如对「v2 功能规格」新版本给出"不受影响"的结论），可撤销；
  - 一条转来的成员提问；一条对外动作申请（例如"把 main 推送到远程仓库"，标"示例"）；一条副作用状态不明（标"示例"）。
- 编造的内容一律标"示例"。

## 一并修复第 1 批遗留的焦点问题

第 1 批的最后一次复检（`tasks/022-recheck-3-report.md`、`evidence/022/recheck-3/assertions.txt` 中的 P03）发现两类焦点问题，本批一起修：
1. 在浮层外点击关闭浮层后，焦点落到了 `body`。如果点击的位置本身不可聚焦，焦点应回到打开浮层的卡片或按钮。
2. 在有筛选的情况下取消一张卡后，这张卡从视图中消失，焦点丢失。焦点应退到相邻的卡片，没有卡片时退到看板容器。

本批新增的项目对话面板、卡片详情滑出面板也要遵守同样的焦点规则：打开时焦点进入，关闭后回到触发它的元素。在测试里加上对应用例。
