# 任务 006：原型更新 A 浏览器页面检查（只检查，不改代码）

## 背景

任务 005 已把 `prototype/index.html` 迁移到项目 / 项目流程 / 节点模型（见 `tasks/005-prototype-v4-a.md` 与 `evidence/005/report.md`）。本任务在真实浏览器中检查页面表现，并保存截图作为证据。

先读：`tasks/005-prototype-v4-a.md`（每项功能应有的表现）、`evidence/005/report.md`（实际的节点 ID、函数名和数据）。

## 要做的内容

1. 启动静态服务：`python3 -m http.server <空闲端口> -d prototype`，端口自选，不要用 8787。
2. 用无头浏览器打开页面。可以使用 Playwright（安装在项目目录以外，例如 `/tmp` 或 npx 缓存），也可以直接使用本机 Chrome 的 headless 模式。视口 1440×900，浅色模式。
3. 按下列场景依次操作，每个场景至少一张整页截图，保存到 `evidence/006/`，文件名以场景编号开头：
   - S01 收件箱首页：恰好 6 个分组（待批准、提问、达到上限、变更请求与退回请求、待验收、待审核的经验库条目），各组有条目
   - S02 项目 A 的项目页：项目流程图中能看出 4 个并行节点，以及汇总结论后的两条条件分支（边旁有"若可行 / 若不可行"）；节点按状态着色
   - S03 打开「技术可行性」节点：信息带（交付物、资料来源、上限进度）、需求 / 边界 / 测试三栏、席位（核对 / 挑错代理标注"只读 · 新上下文"）、有「? 无法判定」的测试及两个人工判定按钮，验收按钮禁用并有提示
   - S04 在该节点展开上下文包：能看到"发送 / 不发送 / 原因"，其中有"保持复核独立"的不发送条目
   - S05 判为通过后验收（`prompt` / `confirm` 对话框直接接受）；已验收横幅中出现「保存为模板」，点击并接受默认名，模板出现在侧栏
   - S06 打开「交付产能」节点：提问阻塞横幅；回答后状态变化（截回答前后各一张）
   - S07 打开「市场调研」节点：达到上限横幅、部分完成报告、三个按钮，token 进度条为错误色；点「追加预算」后再截一张
   - S08 项目 B 的项目页，以及「浏览器检查」节点和「实现」节点：执行记录分别显示 31/34、38/38 和两次实现；有"浏览器检查 → 实现"的退回记录；会话 ID 显示"未记录"
   - S09 退回流程：在页面上对某个可退回的节点发起退回并批准（选择 `evidence/005/report.md` 中说明的演示路径），截图显示被退回节点重新打开、受影响下游标为需重新验证、不受影响节点保持原状
   - S10 代理库：内置 4 个模板；用表单创建一个代理后列表 +1；批准一条 leader 提议后该代理进入列表
   - S11 决策记录：采纳率与决策列表；把"批准节点项目"切换为代理自动（截切换前后）
   - S12 项目设置：执行者为 Codex CLI，Claude Code、Gemini CLI 显示「即将支持」
   - S13 打开某个节点的「执行代理启动 prompt」：模态框含 goal、inputs、rules 三段，强制边界标 [强制]；按 Esc 后模态框关闭（关闭后再截一张）
   - S14 术语扫描：依次打开收件箱、两个项目页、每个节点详情、代理库、经验库、决策记录、项目设置、模板页，用页面可见文本断言不出现"契约""chief""worker""签收""Hub"（此场景可只断言不截图，但要列出扫描过的页面数）
   - S15 深色模式（`colorScheme: 'dark'`）：收件箱、项目 A 项目页、「技术可行性」节点详情
   - S16 窄屏 375×812：收件箱、项目 A 项目页、「技术可行性」节点详情；断言没有横向滚动条（`document.documentElement.scrollWidth <= innerWidth`），三栏变为单列，正文列宽度不少于 280px，文字没有被挤成逐字换行
4. 全程收集浏览器控制台的 error、warning 和未捕获异常，保存到 `evidence/006/console.txt`；没有的话写"无"。
5. 对每个场景用 DOM 查询或页面文本断言关键元素确实存在，不要只截图。断言结果保存到 `evidence/006/assertions.txt`，每行 `PASS/FAIL Sxx 描述`。
6. 文字与背景的对比度：S15、S16 中额外用 `getComputedStyle` 抽查实色按钮、状态标签、流程图节点文字，对比度 ≥ 4.5:1，结果写入断言。
7. 检查脚本保存为 `evidence/006/browser-check.mjs`（或 `.py`），方便复跑。

## 不要做的内容（边界）

- **禁止修改** `prototype/`、`src/`、`FEATURES.md`、`DESIGN.md`、`tasks/` 下除本任务报告以外的任何文件。发现问题只记录，不修复。
- 只允许写入 `evidence/006/` 和本任务的报告文件。浏览器或 Playwright 的安装与缓存放在项目目录以外。
- 不向项目添加任何依赖，不修改 `package.json`。
- 页面中的操作只针对本地静态服务上的原型；不访问其他网站。
