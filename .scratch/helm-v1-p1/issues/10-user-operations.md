# 10 — 用户的直接操作

**What to build:** 用户能暂停、恢复、取消卡片和工作，能打断正在跑的调度轮次。暂停或取消会中止相关的派单并注明原因；工作暂停期间只投递用户消息。见 [spec](../spec.md) 的"用户操作"。

**Blocked by:** 04 — 执行派单主路径

**Status:** ready-for-agent

- [ ] 暂停卡片：中止它正在运行的派单（被中止：卡片暂停），拒绝新派单；恢复后卡片回到推导出的状态并唤醒调度者
- [ ] 取消卡片：中止派单（被中止：卡片取消），进入终态；下游按 03 的规则卡住并唤醒调度者
- [ ] 暂停工作：不改卡片状态，中止该工作所有派单（被中止：工作暂停），拒绝新派单，暂缓投递自动唤醒；用户消息仍唤醒调度者，用户仍可决定关卡
- [ ] 取消工作：中止所有派单（被中止：工作取消），不再唤醒，删除副本和 `_work`
- [ ] 打断：取消当前轮次，立即开新一轮，被取消轮次的事件连同用户消息一起重投，不算失败
- [ ] 用户没有标完成、建卡片、改依赖、派单的操作；终态和固定关卡的约束对用户同样适用
- [ ] 每个用户操作记事件并唤醒调度者
