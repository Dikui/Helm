# 07 — 验收派单

**What to build:** 调度者给卡片派验收单，执行者在新对话里、在同一个卡片副本里检查，用"提交结论"给出通过或不通过；结束后副本被重置，验收者的改动和提交全部丢弃。需要验收的卡片要最近一次验收通过才能标完成；整体验收卡片作为普通卡片能走完。见 [spec](../spec.md) 的"验收与浏览器"。

**Blocked by:** 06 — 标记完成、合并与修复卡片

**Status:** ready-for-agent

- [ ] 验收派单一律新开对话，拒绝续跑
- [ ] 运行层在派单内容前附上派单时的卡片说明快照，记下生效的工作说明版本和被验收的卡片分支 SHA
- [ ] "提交结论"在验收派单里可选通过 / 不通过；未声明不算通过，卡片停在验收中
- [ ] 开始时记卡片分支 HEAD；结束后先清进程，再 `reset --hard` 到该 HEAD 加 `clean -fd`，被 ignore 的依赖和缓存保留；测试覆盖验收者改文件、自己提交都被丢弃
- [ ] 需要验收的卡片须最近一次验收派单为通过才能标完成；取消"需要验收"后可直接标完成，并记事件
- [ ] 整体验收卡片依赖所有其他卡片、只派验收派单，第一次派单时副本含全部成果，标完成时没有新提交、合并跳过
