# 04 — 调度者模板的选择与更换

**What to build:** 用户给项目设默认调度者模板，创建工作时可另选，工作中途可换，从下一个调度轮次起生效。见 [spec](../spec.md) 的"调度者模板"。

**Blocked by:** 03 — 模板文件化与按驱动分派

**Status:** resolved

- [x] 项目有默认调度者模板（默认 `claude-coordinator`），用户可改
- [x] 创建工作时可指定调度者模板，不指定用项目默认；只能选角色为调度者的模板
- [x] 新增用户操作"换调度者模板"，随时可用，记一条事件；`helm` 命令行随之生成子命令
- [x] 正在跑的调度轮次不受影响，下一个调度轮次起用新模板；调度轮次不再写死 `claude-coordinator`
- [x] 主边界测试覆盖：项目默认、创建时指定、中途更换、角色不符被拒、正在跑的轮次不受影响

## Comments

已持久化项目默认与工作调度者模板，提供设置默认和中途更换操作及生成式 CLI，下一轮按工作选择加载模板；主边界覆盖角色校验、创建去重、运行/启动中更换、暂停时 CLI 更换、空闲唤醒、重启保留和旧库升级。
