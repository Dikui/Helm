# 12 — 导出与删除输出

**What to build:** 用户可以把一项已结束工作的输出导出成一个 `.tar.gz`，也可以删除它的原始输出腾出空间；删除前提示先导出，删除后成果、代码和追溯都不受影响。见 [spec](../spec.md) 的"输出管理"。

**Blocked by:** 11 — 输出压缩与超限提示

**Status:** resolved

- [x] 用户操作"导出输出"：只对已结束的工作，参数是目标路径；生成一个 `.tar.gz`，含全部输出文件、成果文件，以及该工作在任务库里的记录 JSON（工作、工作说明各版本、卡片、派单、调度轮次、调度笔记、对话、关卡、事件）
- [x] 用户操作"删除输出"：只对已结束的工作；没有导出过时返回提示，用户确认后才删
- [x] 只删派单输出和调度轮次输出的原始事件流；成果文件、任务库里的派单和事件保留，输出处标"已删除"
