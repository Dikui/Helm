# 11 — 输出压缩与超限提示

**What to build:** 工作结束后它的派单输出和调度轮次输出自动压缩、内容不丢、照样能读；`~/.helm/` 下输出总量超过阈值时提示用户一次。见 [spec](../spec.md) 的"输出管理"。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 工作进入终态（审核被接受或工作被取消）后，把它所有派单输出和调度轮次输出压缩成 gzip，原文件删掉
- [ ] 读输出的操作（如 `get-dispatch-output`）透明解压，返回原内容
- [ ] 新增设置"输出提示阈值"（默认 10 GB），用户可改
- [ ] 压缩和派单结束时统计输出总量；首次超过阈值时列进待处理事项并推送"需要用户处理"事件；降回阈值以下后再超过才再提示
- [ ] 不自动删除任何东西
- [ ] 主边界测试覆盖压缩后可读、阈值调小后只提示一次、降回再超过时再提示、未结束的工作不压缩
