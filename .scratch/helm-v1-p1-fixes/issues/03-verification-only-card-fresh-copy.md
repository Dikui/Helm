# 03 — 只验收的卡片总在工作分支最新成果上验收

**What to build:** 只派验收单的卡片（如整体验收卡片）每次派验收单时，副本都含工作分支此刻的全部成果；在它的上游新增卡片并合入工作分支后，再派的验收单也能看到这些成果。来源：第一版 2048 端到端中，新增的构建卡合入后，整体验收卡片的复验仍在旧提交上运行，因此误判不通过，调度者只好取消旧卡、另建新卡（见 [任务单 15](../../helm-v1-p1/issues/15-default-prompts-and-2048.md) Comments）。见 [spec](../../helm-v1-p1/spec.md)"整体验收卡片是普通卡片"、"验收派单"。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 从没派过执行单的卡片，每次验收派单开始前，卡片分支对齐到工作分支末端，并记一条事件
- [ ] 派过执行单的卡片行为不变（验收看的是它自己的卡片分支）
- [ ] 标完成时没有新提交，合并照常跳过
- [ ] 测试覆盖：整体验收派单之后新增上游卡片并合入，再派的整体验收单的副本包含新卡片的成果
