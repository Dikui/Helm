# 05 — 执行者提示词补齐运行层约定

**What to build:** 执行者的默认提示词写清 Helm 运行层的三条约定，让执行者不再因为不了解运行层而做错：开发服务不用自己停，派单结束时由运行层清理副本里的进程；结束前必须调用"提交结论"，只在文字里写结论算未声明；截图用相对文件名，最终回答写成果列表里的实际路径。来源：第一版 2048 端到端中，验收者试图 kill 服务被沙箱拦下而判失败、一次执行派单漏调"提交结论"、截图写到被拒绝的位置或给出错误路径（见 [任务单 15](../../helm-v1-p1/issues/15-default-prompts-and-2048.md) Comments）。

调度者侧的问题（汇总报告不可靠、派验收单时放宽标准）属于在 Helm 外另做的调度者技能，不在本单范围。把提示词、skill、工具做成按模板的配置属于第二阶段（见 [spec](../../helm-v1-p1/spec.md) Out of Scope），本单不做。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 执行者提示词：开发服务不必自己停，副本里的进程由运行层在派单结束时清理
- [ ] 执行者提示词：结束前必须调用"提交结论"，只在文字里写结论记为未声明、不算完成
- [ ] 执行者提示词：截图用相对文件名，最终回答写成果列表里的实际路径
- [ ] `npm test` 断言上述要点注入了真实执行者驱动使用的提示词
