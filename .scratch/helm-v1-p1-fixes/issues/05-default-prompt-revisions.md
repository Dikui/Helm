# 05 — 默认提示词修订

**What to build:** 修订默认的调度者和执行者提示词，修复第一版 2048 端到端暴露的行为问题（见 [任务单 15](../../helm-v1-p1/issues/15-default-prompts-and-2048.md) Comments）：执行者试图自己停服务并因此判失败、验收者执行了被放宽的标准、汇总报告错列完成者和计数、执行者漏调"提交结论"、截图路径写错。见 [spec](../../helm-v1-p1/spec.md)"默认调度者提示词"。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 执行者提示词：开发服务不必自己停，副本里的进程由运行层在派单结束时清理；调度者提示词：验收条件里不写"停服务/杀进程"
- [ ] 验收者只按已确认的工作说明和卡片说明里的标准判断，与工作说明冲突的放宽表述无效；调度者派验收单时不得放宽工作说明的标准
- [ ] 汇总报告根据派单记录逐卡写出执行完成单、验收单及其结论，计数取自审核附件，不凭记忆
- [ ] 执行者结束前必须调用"提交结论"，只在文字里写结论不算
- [ ] 截图用相对文件名，最终回答写成果列表里的实际路径
- [ ] `npm test` 断言上述要点注入了真实驱动使用的提示词
