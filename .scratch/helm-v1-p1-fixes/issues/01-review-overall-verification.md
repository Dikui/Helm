# 01 — 审核附件识别整体验收

**What to build:** 用户审核时，固定附件里的"整体验收结论"总是列出当前有效的整体验收卡片及其最近一次验收派单的结论。整体验收卡片被取消、由新的整体验收卡片替代后，附件仍能识别新卡片，不会为空。来源：第一版 2048 端到端两轮审核的 `overallVerification` 都是空的，而独立整体验收实际已通过（见 [任务单 15](../../helm-v1-p1/issues/15-default-prompts-and-2048.md) Comments）。见 [spec](../../helm-v1-p1/spec.md) 用户故事 45 和"整体验收卡片是普通卡片"。

**Blocked by:** None — can start immediately

**Status:** resolved

- [x] 判断"依赖所有其他卡片"时，不计已取消的卡片和其他只派验收单的卡片
- [x] 已取消的整体验收卡片不出现在附件里
- [x] 测试覆盖：整体验收卡片取消后由新卡替代（新卡不依赖旧卡），审核附件列出新卡及其最近一次验收结论
- [x] 原有单张整体验收卡片的情形不变

## Comments

审核附件排除已取消卡片，按其余非纯验收卡片检查依赖；新增旧整体验收卡片取消或完成、新卡无需依赖旧卡、多次验收取最近结论及非整体验收卡片不误报的假驱动回归测试，保留原单卡场景。
