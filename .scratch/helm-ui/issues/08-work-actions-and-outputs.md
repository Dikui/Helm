# 08 — 工作操作菜单与输出管理

**What to build:** 工作页"操作"菜单：暂停 / 恢复 / 取消工作（取消需二次确认）、换调度者模板。已结束的工作可导出输出、删除输出，删除前未导出时先提示导出，删除后显示"已删除"。输出总量超过阈值时界面顶部提示，指向设置里的阈值和已结束工作的导出 / 删除。显示卡片副本路径的地方提示别在副本目录开终端。见 [需求文档](../spec.md)"主界面"，界面以 [设计稿](../../../design/INDEX.md) 的 `main.html` 为准。

**Blocked by:** 02 — 界面骨架：托管、收件箱与实时更新

**Status:** ready-for-agent

- [ ] 菜单项按工作状态启用（运行层返回的 `allowedOperations` 优先）；被拒时显示原因
- [ ] 换调度者模板只列可用的调度者模板，调用 `change-coordinator-template`
- [ ] 导出 / 删除调用 `export-outputs`、`delete-outputs`，删除沿用其 `confirm` 流程
- [ ] 超阈值提示由运行层事件或 `get-settings` 得出，低于阈值后消失
- [ ] jsdom 整页测试覆盖暂停 / 恢复、取消确认、换模板、导出、未导出时删除的提示、删除后状态、超阈值提示
- [ ] `npm run check`、`npm test` 通过
