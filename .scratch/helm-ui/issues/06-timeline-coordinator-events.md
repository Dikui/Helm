# 06 — 时间线、调度者与事件标签

**What to build:** 调度结构视图的其余三个标签。时间线：每张卡片一条泳道，执行和验收派单是色块，重叠表示并行，"验收 ✗ → ↺ 执行"表示打回，竖线表示现在。调度者：当前状态（运行中 / 空闲 / 连败暂停）、每个调度轮次及其按步骤的输出、调度笔记各版本。事件：可按卡片、派单、执行方筛选的事件时间线，点事件跳到对应派单输出的那一步。见 [需求文档](../spec.md)"运行层补的读取"中 `get-round-output`、"主界面"，界面以 [设计稿](../../../design/INDEX.md) 的 `main.html` 调度结构视图为准。

**Blocked by:** 04 — 对话视图与调度者引导；05 — 卡片图与卡片检查器

**Status:** resolved

- [x] 新增 `get-round-output`（调用方 `user`），按步骤读取调度轮次输出，分页方式与 `get-dispatch-output` 一致；照常进 MCP 和命令行
- [x] 泳道和色块由派单起止时间和用途得出，运行中的派单随时间延伸
