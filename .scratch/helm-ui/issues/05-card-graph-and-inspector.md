# 05 — 卡片图与卡片检查器

**What to build:** 调度结构视图的"图"标签：卡片自上而下分层，同层可并行，连线表示依赖并汇合，关卡是节点，取消的卡片虚线保留，打回次数标 ↺；每张卡片显示状态、执行者模板、当前步骤号和最新一步摘要并实时更新；可平移缩放，悬停高亮上下游。点卡片在右侧检查器看派单历史（结束方式、自报结论及理由、最终回答、打回回路）、按步骤看派单输出、看成果，并能暂停 / 恢复 / 取消卡片（取消需二次确认）。见 [需求文档](../spec.md)"主界面"，界面以 [设计稿](../../../design/INDEX.md) 的 `main.html` 调度结构视图为准。

**Blocked by:** 02 — 界面骨架：托管、收件箱与实时更新
