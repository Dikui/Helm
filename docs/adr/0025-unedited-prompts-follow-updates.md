# 没改过的规则提示词随 Helm 更新

ADR 0008 规定数据目录里已有的规则提示词一律不覆盖。结果是在其他设备上更新 Helm 后，新版提示词永远到不了 `~/.helm/prompts/`，只能手动复制（issue #6）。用户 2026-11-03 提出要让提示词随版本更新。

`helm serve` 每次启动时，对每一段规则判断用户是否通过设置页（`set-prompt`）保存过：事件日志里有该段的 `prompt-set` 事件就算改过，保留原文件；没有就用仓库 `prompts/` 覆盖。缺文件照旧补上。判断依据用已有的事件日志，旧安装无需迁移，也不需要额外的标记文件。

代价：直接在 `~/.helm/prompts/` 里手改、没经过设置页的内容，下次启动会被覆盖。改过的段落此后不再跟随更新，想要新默认仍需自己对照仓库合并。

## Considered Options

- **保持不覆盖**（ADR 0008）：其他设备拿不到新提示词。
- **每次启动全部覆盖**：会丢掉用户在设置页的修改。
- **保存上次播种内容的副本，比对文件是否被改**：能识别手改，但旧安装没有副本可比，第一次仍无法判断，还要多维护一份文件。
