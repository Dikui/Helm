# Agent 自行恢复工具和环境故障

ADR 0026 去掉沙箱后，提示词禁止安装浏览器、重启服务只会阻止正常恢复；浏览器退出和单个库条目组装失败仍会让运行层直接结束 Agent。用户在 issue 30 决定：运行层提供默认做法，不把它变成唯一做法。注入的工具或环境坏了，Agent 可以自行修复或换方法，最后说明恢复过程。

- 辅助工具故障不结束 Agent：运行层清理故障资源，交回脱敏后的错误原文。浏览器启动失败仍启动执行者，运行中退出后的工具调用返回退出原因，不自动重启。正常结束之外，仅超时、撤销、用户取消或 Agent 自身退出结束派单。
- 单个 skill 或 MCP 组装失败跳过该项，以 toolProblems 和事件说明原因；保存和检查配置时仍报告名字冲突、驱动不支持等配置错误。快照保留原配置，调度者续跑比较跳过项的类型和名字；故障持续可续跑，修好后新开会话以收到工具。
- 恢复顺序：执行者自己修 → 换方法 → 记未验证并说明尝试 → 调度者诊断、换驱动或重派 → 带保留意见交审核。缺凭据直接记未验证。调度者可先看内容，再用 shell 切回分支、中止合并、保留或清理 Helm 卡片副本和 _work 的改动，修好后重试；项目目录不动。
- 硬边界保留：不推送、不部署、不输出凭据值；验收不能改产品代码让检查通过；执行者不提交 Git、不改 Git 配置。服务只动自己启动的进程，浏览器无头运行且使用独立用户数据目录，不碰用户浏览器配置；运行层照常清理派单剩余进程。

## Consequences

- 验收可能在没看页面时提交 passed；同批任一验收票发生过 browser-failed，整批结束后不自动完成，唤醒调度者判断。
- Agent 自行安装的依赖、浏览器等会留在机器上，不随派单清理。
- 调度者可用 shell 修复副本 Git 状态；诊断包含路径、期望分支、当前 HEAD 和限长的状态或冲突文件，修复前须看内容。

## Considered Options

- **修复单**：运行层多一条分支路径；调度者直接修复同时覆盖卡片副本和 _work，不另建修复单。
- **运行层自动重启浏览器**：会丢失页面状态并隐藏原始错误，交给执行者决定如何恢复。
