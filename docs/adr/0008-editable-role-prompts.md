# 角色规则提示词放进数据目录，仓库只提供初始默认

ADR 0006 把调度者和执行者的工作规则写死在 `src/prompts.ts`，好处是规则改进随 Helm 更新生效，代价是用户要改规则（例如汇总报告的写法）只能改源码再重启。用户 2026-10-25 决定规则可在设置页改：四段规则（调度者规则、调度者运行约束、执行者规则、执行者运行约束）存在 `<dataDir>/prompts/<名字>.md`，与 `agents/`、`library/` 并列。仓库的 `prompts/` 只是初始默认：`helm serve` 启动时把缺少的文件复制过去，已有文件一律不覆盖，此后 Helm 只读数据目录。

用户明确不要"没改过就跟随更新"的判断：仓库更新不再影响已有安装，想要新默认就自己对照仓库合并，或删掉对应文件后重启让它重新复制。拼装顺序不变：规则、Agent 自己的 `prompt.md`、运行约束。规则随 Agent 一起读入快照，记在派单和调度轮次的 `agent_snapshot` 里，改动从下一次派单或调度轮次起生效。

运行约束同样可改，即使其中有运行层依赖的约定（例如必须调用 submit-conclusion）。改坏的后果由用户承担，Helm 不校验内容。

## Considered Options

- **内置在代码里**（ADR 0006 原状）：更新自动生效，但用户无法在运行时调整。
- **按段覆盖，未覆盖的段跟随更新**：要区分"用户改过"和"默认"，用户不要这层判断。
