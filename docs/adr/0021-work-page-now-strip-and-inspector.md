# 工作页改为现在条 + 常驻对话 + 检查器

原工作页在“对话 / 调度结构 / 工作说明”三个视图间切换：看卡片图时对话不见了，回到对话又看不到卡片；调度者本轮在做什么藏在输入框上方，合入、推送失败用大横幅挡住对话。2026-10-31 调研了同类产品（Codex app、Cursor Agents Window、Claude Code 桌面、Conductor、Devin、Airflow），它们的第一屏都是“列表 + 当前状态”，依赖图放在展开层；Devin 撤掉了独立视图，Airflow 要求选中任务后日志和操作留在原地。用户确认 v3 设计稿后决定：对话常驻中栏，顶栏下一条现在条（调度者、等你、活卡片、说明 / 结构 / 报告 / 交付入口），点格子在右侧检查器打开对应内容，检查器默认内容随阶段变化，可放宽或收起；待决定的关卡和交付失败用对话顶部的紧凑钉栏；收件箱分“等你 / 在跑 / 安静”三段。

路由随之改为 `/works/:id?inspect=…`，旧的 `/works/:id/<视图>` 只做重定向。依赖图、时间线、调度轮次、事件仍是原组件，降为检查器里的“结构”子标签。

## Considered Options

- **单面板切换（原型变体 B）**：仍是一次只看一样，没解决对话与结构互相替换。
- **对话优先 + 抽屉（原型变体 C）**：结构要临时打开，执行中频繁看卡片时来回开关。
- **看板或网格作首页**：表达不了依赖、汇合和打回，Helm 每项工作只跑一次，看板的列也不稳定。
- **活文档式工作页**：汇合、打回、跳过（ADR 0015）用缩进清单表达别扭。
